# tony11-dot.github.io

Public pages for ClassNotes, served by GitHub Pages at
<https://tony11-dot.github.io/classnotes/>: support (`index.html`), the privacy
policy, terms of use, accessibility statement and account deletion.

The pages are generated from one template; edit the text between `<article>`
and `</article>`. `site.css` (light and dark) and `site.js` (the "On this page"
list) are shared. Inter is self-hosted in `classnotes/fonts/` (SIL OFL 1.1).
Contact address on every page: support@classmateapp.org.
